# Design System

The portfolio uses a calm editorial design built around career progression.

## Foundations

- Neutral light and dark surfaces
- Restrained green accent
- System-native sans-serif and monospace stacks
- Fluid spacing and type scales
- Fine dividers that establish reading order
- Motion limited to feedback and impact count-up

## Breakpoints

| Width  | Behaviour                                    |
| ------ | -------------------------------------------- |
| 1120px | Compact navigation and stacked hero          |
| 820px  | Single-column section introductions          |
| 560px  | Vertical content flow and full-width actions |
| 320px  | Minimum supported viewport                   |

## Brand boundary

The site is personal and does not reproduce the TD design system. Official TD employer markers
appear only beside actual career roles.

See
[docs/design-system.md](https://github.com/CRSD-Lau/Personal-Site/blob/main/docs/design-system.md)
