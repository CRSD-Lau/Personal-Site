# Neil Mitchell Portfolio v3.0.3

Author: Neil Mitchell
Last modified by: Neil Mitchell
Release date: 6 September 2026

Menu links to About, Experience, Works, Approach, Expertise, Impact, and Contact now place their introductions
just below the sticky header at the requested mobile positions. Contact retains a slightly
larger gap. Normal spacing between sections is unchanged.

The adjustment uses the existing native links and section IDs. Direct links, reloads,
repeated menu selections, and links back from the Works page continue to work. Navigation
without JavaScript retains its original offset to accommodate the additional visible links.

Delivery-step headings now align with the first line beside each numbered marker. Round and
square list bullets also align with the first line of their copy, including wrapped text.

The mobile header keeps the theme, résumé, and menu controls anchored right with equal gaps.
Both hamburger and close icons are centered within their 44px controls. The footer title is
centered below the name, and borderless LinkedIn and GitHub icons link to Neil's profiles.

No career details, metrics, résumé content, or project claims changed.

## Verification

- Full project validation: formatting, lint, TypeScript, content checks, and static build.
- 14 layout scenarios across 320px, 360px, 393px, 430px, 760px, 768px, and 1280px widths

  footer alignment, social links, and keyboard focus.
