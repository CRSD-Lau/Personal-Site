# Neil Mitchell Portfolio v2.2.2

Version 2.2.2 is a dependency-maintenance release that brings the supported web toolchain current
without changing portfolio content, project evidence, licensing boundaries, or the visual design.

## Runtime and tooling

- Updates Next.js and the matching Next.js ESLint integration to 16.3.0.
- Keeps the already-current React and React DOM runtimes on 19.2.8.
- Updates `@types/react` to 19.2.18 and `@types/react-dom` to 19.2.4.
- Updates `globals` to 17.9.0 and `typescript-eslint` to 8.66.0.
- Uses the TypeScript 7 native compiler explicitly for project type-checking while the standard
  TypeScript 6 package provides the compiler API required by Next.js and `typescript-eslint`.

## Node compatibility decision

Production, GitHub Actions, and local development remain on Node.js 24 LTS. The matching
`@types/node` 24.13.3 release is the newest definition package for that runtime line.

Dependabot PRs
[#5](https://github.com/CRSD-Lau/Personal-Site/pull/5) and
[#6](https://github.com/CRSD-Lau/Personal-Site/pull/6) are included in this combined release. PR
[#7](https://github.com/CRSD-Lau/Personal-Site/pull/7) is intentionally not merged because it would
describe the APIs of the end-of-life Node.js 25 runtime while production still runs Node.js 24.
Dependabot now ignores unsupported Node and TypeScript major updates so future proposals stay aligned
with the deployed stack.

## Verification

- A clean npm install completes successfully on Node.js 24.
- Formatting, ESLint, TypeScript 7 native type-checking, content validation across 76 files, and the
  static production build pass.
- The export includes the home page, Works index, Deep Live Cam case study, metadata routes, and
  social assets.
- `npm audit --audit-level=high` reports zero known vulnerabilities.
- GitHub Actions, CodeQL, Vercel Preview, and the exact production deployment are required to pass
  before the release tag is published.
