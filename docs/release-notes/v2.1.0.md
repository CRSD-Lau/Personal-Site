# Neil Mitchell Portfolio v2.1.0

Version 2.1.0 strengthens how the portfolio is shared, maintained, validated, and released without
changing Neil's career record or the site's established editorial design.

## Visitor-facing changes

- Makes `https://neilmitchell.ca` the canonical domain across page, social, and discovery metadata.
- Adds a 1200 x 630 editorial preview for polished embeds on LinkedIn, Slack, Discord, Facebook,
  iMessage, and X.
- Adds complete Open Graph and X card metadata.
- Adds public manifest, robots, and sitemap routes.
- Replaces the initials favicon with a round crop of Neil's headshot.
- Refines the header Connect action so it follows the site's visual language.
- Preserves the existing page layout, copy, résumé, career history, and responsive behaviour.

## Maintainer changes

- Standardizes development, GitHub Actions, and Vercel builds on Node.js 24.
- Uses the TypeScript 7 native compiler for project type-checking.
- Uses the official TypeScript 6 compatibility API for Next.js and `typescript-eslint` during the
  TypeScript 7.0 transition.
- Removes unused Tailwind CSS, Autoprefixer, direct PostCSS tooling, and their configuration files.
- Replaces Tailwind's base layer with a focused CSS normalization layer.
- Pins the PostCSS copy required transitively by Next.js to a patched version.
- Expands content validation to protect runtime alignment, compiler aliases, release notes, and the
  streamlined CSS toolchain.
- Refreshes the README, architecture, development, deployment, release, and wiki documentation.

## Verification

- A clean `npm ci` install succeeds.
- Formatting, ESLint, TypeScript 7 type-checking, TypeScript 6 compatibility checking, content
  validation, and the Next.js static production build pass.
- `npm audit` reports zero known vulnerabilities.
- Full-page mobile, tablet, and desktop screenshots are byte-for-byte identical to the pre-upgrade
  design baseline.
- Checks at 320px, 768px, 1280px, and 1600px show no horizontal overflow or broken images.
- Light and dark themes, mobile navigation, static metadata routes, and the public résumé work
  locally without browser console errors.

## Compatibility note

TypeScript 7.0 does not yet expose the programmatic compiler API used by Next.js and
`typescript-eslint`. The repository therefore follows Microsoft's supported side-by-side transition
model. Node.js 26 type definitions are intentionally excluded while Vercel production remains on
Node.js 24.

## Rollback

Version `v2.0.0` remains the previous known-good release and Vercel deployment.
