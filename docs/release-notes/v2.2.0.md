# Neil Mitchell Portfolio v2.2.0

Version 2.2.0 adds an independent Works section without displacing the portfolio's CV-focused home
page. The first case study presents Deep Live Cam Studio as technical delivery work with fixed
evidence, clear attribution, and responsible-use boundaries.

## Visitor-facing changes

- Adds a Works section to the main portfolio and a dedicated `/works` project index.
- Adds a public Deep Live Cam Studio case study covering the problem, delivery system, audited
  results, release governance, and transferable practice.
- Presents four fixed August 3, 2026 evidence measures: 158 authored post-fork commits, 20 merged
  pull requests, 510 passing automated tests, and separate CUDA and DirectML Windows profiles.
- Includes the project's reviewed repository social preview plus original release-flow and growth
  visuals with accessible text alternatives.
- Keeps project attribution, the AGPL-3.0 licence and compliance links, upstream history, consent,
  and lawful-use guidance visible. The reused preview is explicitly excluded from the portfolio's
  all-rights-reserved terms and retains its source-project terms.
- Refines Works navigation, route scrolling, governance-panel spacing, and project-card corners so
  the new pages remain consistent with the main editorial design.
- Expands the public technical profile and résumé with hands-on AI workflows, software development,
  automation, and a direct portfolio link.
- Removes the private phone number from the public résumé and adds a stable search-engine favicon.

## Maintainer changes

- Adds a typed project-content source that can support more case studies without new routing or
  navigation structures.
- Statically exports `/works` and `/works/deep-live-cam` with canonical URLs, social metadata,
  CollectionPage and CreativeWork structured data with a nested software-source record, and sitemap
  entries.
- Extends content and export validation to enforce the audited metric labels, attribution language,
  responsible-use copy, preview hash, external links, and publication boundaries.
- Extends the local static server to resolve nested exported routes without trailing slashes.
- Updates `brace-expansion` to `5.0.9` to resolve the high-severity denial-of-service advisory found
  by `npm audit`.

## Verification

- Formatting, ESLint, TypeScript, content validation, and the static production build pass.
- The exported Works index, case study, metadata, structured data, sitemap, and social asset pass
  release validation.
- Desktop and mobile navigation, cross-route scrolling, theme switching, panel spacing,
  project-card styling, and horizontal overflow are checked in the local production preview.
- Release validation confirms reduced-motion rules, visible focus treatment, conditional mobile-menu
  rendering, and the growth chart's text alternative.
- `npm audit` reports zero known vulnerabilities before publication.
- GitHub Actions, CodeQL, Vercel Preview, and the production deployment are checked on the released
  commit.

## Known limitations

- Project figures are a fixed August 3, 2026 audit snapshot, not live GitHub counters.
- The case study is a technical portfolio summary, not legal advice, and does not distribute the
  application, models, runtime binaries, or private audit material.
