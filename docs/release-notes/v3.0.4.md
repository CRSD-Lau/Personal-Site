# Neil Mitchell Portfolio v3.0.4

Author: Neil Mitchell
Last modified by: Neil Mitchell
Release date: 6 September 2026

Saved app icons now use opaque headshot images, with a separate Android maskable icon and an Apple
touch icon. This avoids the white surround platforms can add to transparent, non-maskable icons.
The operating system still chooses the final home-screen shape.

Installed launches show a borderless, 144px circular headshot at the horizontal and vertical center
of the visible viewport. It holds for 1.8 seconds and fades for 250ms, with no fade for reduced
motion. The introduction runs once per browsing session; ordinary browser visits open immediately.
Keyboard or pointer interaction dismisses the introduction early.

The launch screen activates before page paint and does not depend on React hydration. JavaScript
and storage failures leave the portfolio accessible. CSS and timer dismissal prevent a stuck
screen. The browser's own native splash duration remains controlled by the platform.

Existing shortcuts may retain their cached image. If the old icon remains after deployment,
remove the saved shortcut and install the site again.

## Verification

- Formatting, lint, TypeScript, content validation, and production static export.
- Browser checks at 320px, 390px, 768px, 1280px, and 1600px in both themes.
- Circle dimensions, exact viewport centering, timing, rotation, early dismissal, repeated
  navigation, reduced motion, delayed JavaScript, unavailable storage, and disabled JavaScript.
- Exported icon dimensions, opaque pixels, maskable safe area, Apple metadata, and image author
  and modifier metadata.

Browser checks simulate standalone Android and iOS modes. Actual launcher appearance and the
native splash still require an installed-device check.
