# Neil Mitchell Portfolio v3.0.0

Author: Neil Mitchell
Last modified by: Neil Mitchell
Release date: 5 September 2026

## Visitor experience

The portfolio now opens with a photographic introduction, a clear delivery statement,
and direct access to career experience and the résumé. Locally hosted Manrope typography,
forest and pale lime colours, and responsive light and dark themes carry through all
three public routes.

The current role is featured prominently. Earlier responsibilities expand on demand,
with every career summary and date retained. Independent work follows Experience, with
a larger project feature, a simpler Works index, and clearer case-study navigation.
Contact actions and other buttons use concise labels without arrows.

## Career content and project attribution

The capability label now reads ML Engineering Delivery. The résumé, career dates,
supported metrics, and approved project artwork are unchanged. The Deep Live Cam Studio
case study retains its fixed evidence snapshot, upstream attribution, licence links,
and responsible-use guidance.

## Maintenance and reliability

- Added design documentation and a detailed review report with browser evidence.
- Kept static route navigation compatible with ordinary static hosting.
- Preserved theme switching when browser storage is unavailable, readable print output,
  reduced-motion behaviour, and navigation without JavaScript.
- Updated the ESLint filesystem dependency to patched `@humanfs/node` 0.16.8 and its
  required support packages.
- Kept Node.js 24 and the existing Next.js, React, and TypeScript architecture.

## Verification

Local validation covers a clean dependency install and audit, formatting, lint,
TypeScript, content guardrails, static export, and generated metadata and assets.
Browser review covered three routes at six widths in both themes, career disclosures,
accessibility scans, keyboard navigation, theme persistence, clipboard behaviour,
reduced motion, printing, storage denial, and JavaScript-disabled navigation.

The final release is published only after hosted CI, CodeQL, and Vercel Preview pass,
and the exact production commit is verified at https://neilmitchell.ca.

## Known limits

Browser testing uses Chromium; Safari, Firefox, and physical devices have not been
tested. Automated accessibility checks do not replace assistive-technology testing.
The review's Lighthouse scores are local laboratory measurements, not production
visitor measurements.
