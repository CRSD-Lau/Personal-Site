# v3.0.6

Author: Neil Mitchell
Last modified by: Neil Mitchell

This release improves image loading and closes the actionable items from the website launch
checklist review.

- Added responsive WebP display images for the portrait and project preview. The original
  photographs and social cards remain unchanged; derivative metadata and licensing are retained.
- Limited the installed-app introduction image download to installed-app visits.
- Added a plain-language privacy page, linked from the footer and included in the sitemap, with
  complete route metadata and structured data.
- Added a branded 404 with home and Works recovery links, a real 404 response, and noindex metadata.
- Added rendered gradient-contrast measurements alongside automated accessibility checks, plus
  image-size, metadata, and route checks to prevent regressions.

The existing palette, career claims, résumé, social previews, and main call to action are preserved.
The site still uses no advertising scripts, client analytics, account registration, or contact form.
